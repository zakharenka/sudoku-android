# Sudoku 1.1.0

Release date: 2026-11-10
Tag: `1.1.0`
Version code: `1001000`

## New

- **Game history.** The current game, unfinished games and solved games are
  kept in one list, grouped by start date. Each row shows a mini puzzle
  preview, difficulty, start and finish dates, elapsed time and mistakes.
  Tapping a row opens that game on pause, including a solved one.
- **Records from history.** Best times and solved counters are no longer stored
  separately: they are derived from solved games and split into **No mistakes**
  (`errors == 0`) and **With mistakes** (`errors > 0`) categories, with a
  switch between them.
- **Backup and restore.** Settings now has export and import through the
  system file picker. Import validates the file and replaces all local history
  only after confirmation; an invalid file changes nothing.
- **Show mistakes option.** The new-game dialog has a "Show mistakes"
  checkbox. Its value is saved with the game, and hidden-mistakes games keep
  `errors == 0`, so they join the **No mistakes** category.
- **Handwritten digits.** Cell values are drawn as animated pencil strokes and
  reversed on erase. The settings toggle switches them to plain digits of the
  same size.
- **Keyboard input.** Digits `1–9` and the numpad enter values; `0`, Backspace
  and Delete erase; arrow keys move the selection and stop at the board edges.
  Input is ignored while a dialog is open, during loading, pause or victory.

## Improved

- Settings and dialogs share a compact layout with a fixed header and
  scrollable content; the language row, data actions and About are grouped
  clearly.
- Same-digit highlighting can be disabled without affecting peer highlighting.
- Opening a dialog pauses the game, stops the timer and blocks keyboard input.
- Pause on background: the current game is saved when the app leaves the
  foreground and restored on pause next time.
- Larger fonts and control heights across the interface.
- Hints remain limited to three per game, are saved with the game and can be
  erased or undone without refunding the counter.
- F-Droid auto-updates are enabled through `fdroid/version.json` and
  tag-based update checks.
- Updated translations for all nine languages.

## Notes

- The saved game and history now live in one versioned local data file.
  SharedPreferences keeps settings only.
- Old `best:*`, `solved:*` and `saved_game` data from 1.0.x is intentionally
  not migrated and is ignored. Records start from the games played in 1.1.0.
- Minimum Android version: Android 11 (API 30).
- The app works fully offline, contains no ads or analytics and requests no
  permissions.
- Prepared for Google Play and F-Droid from the same tagged source. F-Droid
  builds are signed with the F-Droid key; switching from Google Play requires
  uninstalling the Play version first.
