# Sudoku 1.0.0

Release date: 2026-10-31
Tag: `1.0.0`
Version code: `1000000`

## Highlights

- First public release.
- Classic 9×9 Sudoku with a hand-drawn paper-and-ink interface: paper
  texture, wobbly lines, square grid and the Neucha handwritten font.
- Four difficulty levels: Easy, Medium, Hard and Expert.
- Every puzzle is generated with exactly one solution.
- Notes, hints, undo and erase.
- Timer, mistake counter and pause.
- The current game is saved automatically and restored on pause.
- Best time and solved puzzle count for each difficulty.
- Nine languages: English, Russian, Spanish, Portuguese (Brazil), French,
  German, Italian, Ukrainian and Belarusian.
- Light, dark and system themes.
- Adaptive layout for phones and tablets.
- Hand-drawn adaptive app icon with light, dark and monochrome layers.
- Fully offline: no ads, no analytics, no accounts and no permissions.

## Notes

- Minimum Android version: Android 11 (API 30).
- The language is selected through the native Android app-language settings.
