# Sudoku 1.3.2

Release date: 2026-11-16
Tag: `1.3.2`
Version code: `1003002`

## Fixed

- **Notes no longer reveal wrong entries.** Placing a digit clears that digit
  from the notes of its peers (same row, column and box) even when the digit is
  wrong. Previously the notes stayed in place on a wrong digit, so in games
  with hidden mistakes they showed whether an entry was correct. Undo restores
  the removed notes.

## Notes

- The saved game and history format is unchanged; data from 1.3.1 loads as is.
- No other rule changes.
- This release is prepared for both Google Play and F-Droid from the same
  source tag.
