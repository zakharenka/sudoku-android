# Sudoku 1.2.0

Release date: 2026-11-12
Tag: `1.2.0`
Version code: `1002000`

## New

- **History status.** Each history row now shows whether a puzzle is solved
  or still in progress. The mini preview stays, so a game can be recognised at
  a glance.
- **History stats.** Mistakes and used hints are shown in one right-aligned
  line next to the elapsed time; zero counters are omitted. Large histories
  (more than 50 games) use a lazy list and no longer stall the app.
- **Records from history.** The trophy button in the History dialog opens the
  records, so the game header keeps only Rules, History and Settings and the
  title fits at any font scale.

## Improved

- **System font scaling.** The interface keeps working up to a `2.0` font
  scale: titles auto-size, labels wrap instead of clipping, the game toolbar
  stays on one line and the action row switches to a `2×2` grid at `1.4` and
  above. Dialog, settings and history rows grow with their text.
- **Number pad.** The remaining count moved under the digit and is styled like
  the hint badge. The digit keeps the board cell size and the same stroke
  weight as a clue, with compact and even padding inside the key.
- **Handwritten digits always on.** The setting was removed; the board and the
  number pad now use the same handwritten digit everywhere.
- **Icons.** Play and refresh are drawn with the same sketch strokes as the
  rest of the interface. Action, pause and new-game icons are larger, and the
  undo and refresh icons were redrawn.
- Updated translations for all nine languages.

## Notes

- The saved game and history format is unchanged; data from 1.1.0 loads as is.
- The handwritten-digits setting is not read any more and is ignored if it is
  still present in old preferences.
- No rule changes.
- This release is prepared for both Google Play and F-Droid from the same
  source tag.
