# Sudoku 1.0.4

Release date: 2026-11-08
Tag: `1.0.4`
Version code: `1000004`

## Changes

- The board frame is drawn as a separate layer centered on the outer grid
  line, so the grid lines meet it and the edge cells keep a consistent
  selection inset.
- Board digits are larger.
- Notes are shown in ascending rows in the top-left corner of a cell, using
  the same colour and weight as digits; six to nine notes are split into two
  balanced rows and scaled to fit.
- The remaining-digit and hint counters are larger and have more contrast.
- F-Droid auto-updates are enabled through `fdroid/version.json`.

## Notes

- No rule changes.
- This release is prepared for both Google Play and F-Droid from the same
  source tag.
