# Sudoku 1.3.0

Release date: 2026-11-14
Tag: `1.3.0`
Version code: `1003000`

## New

- **Fast input mode.** Turn on Fast mode in the action row and pick a digit on
  the number pad. The digit is armed and highlighted instead of being written
  straight away; each cell tap then places that digit and selects the cell. In
  notes mode the same tap toggles the note. Tapping the armed digit again
  disarms it, and arming clears on a new game, on victory, when the digit is
  fully placed and when the mode is turned off.
- **Fifth action button.** The action row now has Undo, Erase, Notes, Fast
  mode and Hint. Labels auto-size and the row uses a five- or three-column
  grid depending on the width.

## Improved

- **Android 8.0 and newer.** The minimum version is lowered from Android 11
  (API 30) to Android 8.0 (API 26). The library stack is unchanged; the
  API 27-only navigation-bar theme attribute moved to `values-v27`.
- **Translations.** The Fast mode strings are translated into all nine
  languages.
- **Store screenshots.** The phone, 7-inch and 10-inch sets were regenerated
  with realistic data in both grid styles, history, records, rules and the dark
  theme.

## Notes

- The saved game and history format is unchanged; data from 1.2.0 loads as is.
- Fast mode is stored in the settings (`fast_input`) and is off by default. The
  armed digit is not saved with the game.
- Keyboard input keeps the cell-first order and does not arm a digit.
- No rule changes.
- This release is prepared for both Google Play and F-Droid from the same
  source tag.
