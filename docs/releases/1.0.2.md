# Sudoku 1.0.2

Release date: 2026-11-07
Tag: `1.0.2`
Version code: `1000002`

## New

- **Board line style.** Settings → Board lets you switch between straight
  grid lines (the new default) and the original hand-drawn wobbly lines. Only
  the 9×9 board, its frame and the selection outline change; the rest of the
  interface keeps the sketch style.
- **Hint limit.** Each game now has three hints. The remaining count is shown
  on the Hint button, saved with the game and restored on pause. Undo does not
  refund a used hint.

## Improved

- The saved-game format is now version 2; existing version 1 saves still load,
  with no hints used.
- Updated translations and in-app rules for all nine languages.
- F-Droid build metadata, fastlane store texts, screenshots and changelogs.
- The project is now licensed under GPL-3.0-or-later, with the full license
  text in the repository.
- Documentation translated to English.

## Notes

- Minimum Android version: Android 11 (API 30).
- The app works fully offline, contains no ads or analytics and requests no
  permissions.
- F-Droid builds are signed with the F-Droid key. Users switching from the
  Google Play version must uninstall it first; local records and the saved
  game will be lost.
