# Sudoku 1.0.3

Release date: 2026-11-08
Tag: `1.0.3`
Version code: `1000003`

## Changes

- Removed the foojay toolchain resolver plugin from `settings.gradle.kts`.
  The F-Droid scanner flags it as a usual suspect, and the build does not need
  it because the project does not use Gradle Java toolchains.
- No gameplay, interface or data-format changes.

## Notes

- This is the first release prepared for Google Play and F-Droid from the same
  source tag.
- The app itself is identical to 1.0.2 for players; this is a build-only
  maintenance release.
- F-Droid builds are still signed with the F-Droid key, while Google Play uses
  Play App Signing. Users switching channels must uninstall first.
